# Nekomi v1.0.0

Nekomi 是一个基于 Astro、MDUI 2.1.5 与 Material Design 3 的静态博客主题。修改配置和 Markdown 即可搭建个人站点，不需要 React、Vue 或常驻 Node.js 服务。

## 主要功能

- Stellar 风格的融入式侧栏、顶部 Tabs、移动端 App Bar / Drawer；支持浅色、深色和跟随系统，以及 Default、Fresh、Minimal 外观预设。
- Astro Content Collections 与 Markdown 写作，Shiki 双主题代码高亮、代码复制、目录与锚点、阅读时间、相关文章和上一篇 / 下一篇导航。
- 正文图片灯箱支持缩放、拖动、触摸与键盘；本地图片由 Astro 优化为响应式资源。
- 构建时 KaTeX 公式、按需 Mermaid 图表，以及提示块、折叠、图片组、链接卡片、点击加载视频、原生 MDUI 内容 Tabs。
- ClientRouter 无刷新导航、共享元素过渡、跨页保留壁纸 DOM；返回列表恢复筛选条件、文章批次和滚动位置，支持减少动态效果。
- 静态分页与可选无限滚动、全量文章搜索、分类 / 标签 / 归档，以及独立友情链接页。
- 可配置的 SEO、Canonical、Open Graph、JSON-LD、RSS、Sitemap 和根 / 子路径部署。
- 可选 Waline、Twikoo、Giscus、Artalk 评论及自建 CommentAdapter；浏览器连接独立服务，主题不提供评论后端。
- 统一站点配置、Zod 校验与 JSON Schema，支持模块顺序、导航、社交链接、外观和文章级开关。
- 分类配色、侧栏名称、界面文案、日期时区、首页预览、普通顶部链接与可选自托管 WOFF2 均可配置；界面语言可显式覆盖，文章与评论正文不被改写。
- 可选侧栏与评论区角色装饰（默认关闭，自备合法素材），支持浅深来源、安全退让；站点图标、移动端壁纸和侧栏预览数量均可配置。

## 环境要求

- **Node.js ≥22.23.4**，推荐 **Node.js 24 LTS**。
- npm **≥9.6.5**；使用仓库的 `package-lock.json` 和 `npm ci`。
- 只在开发和构建时需要 Node.js，生产部署 `dist/` 的静态文件。

## 安装与运行

可以在仓库启用 GitHub Template 后选择 **Use this template → Create a new repository**，或克隆代码。Tag 创建后，以下命令可取得固定的 1.0.0 版本：

```sh
git clone --branch v1.0.0 https://github.com/kylin930/Nekomi.git my-blog
cd my-blog
git switch -c my-blog
npm ci
npm run dev
```

开发地址为 `http://localhost:4321`。日常编辑：

```text
site.config.json          站点信息、外观、导航和功能
src/content/posts/*.md    Markdown 文章
src/assets/images/       可优化头像、封面和正文图片
public/                  按原路径发布的静态资源
```

构建与本地预览：

```sh
npm run check
npm run build
npm run preview
```

将 `dist/` 部署到 GitHub Pages、Cloudflare Pages 或其他静态托管平台，不需要 SPA fallback 或生产 Node.js 服务。生产地址通过 `publishing.url` / `publishing.base`，或 `SITE_URL` / `SITE_BASE` 配置；子路径只写入 base，不能重复放入源站地址。

## 发布自己的内容

模板中的三篇示例保留 `demo: true`，继续 noindex，并排除 RSS、Sitemap 和真实文章结构化数据。文章顶部已移除示例标签，**显示变化不代表示例变成正式内容**。

发布真实文章时填写自己的元数据；仅对真实内容使用 `demo: false`。确认生产地址后，再将全站 `demo` 设为 `false`、`publishing.indexing` 设为 `true`。评论、统计和壁纸默认关闭，不会默认连接原站个人图片 API。

从开发版本升级前，请备份自己的配置、文章、图片和自建适配器。已有配置和文章格式继续适用，本次不要求迁移内容；详情见 README 的更新说明。

## 验证与已知边界

发布前执行构建、Astro Check 及 Markdown、评论、SEO、主题配置和客户端导航的核心回归；具体覆盖与结果见测试文档。示例站没有可索引页面时，Sitemap 的 “No pages found” 提示属于预期。

Mermaid 是较大的可选依赖，仅在含图表的文章接近图表时加载。第三方评论需要自行配置独立服务；视频只在读者点击后加载，实际播放、登录与地区限制由平台决定。浏览器自动化主要覆盖 Chromium，评论使用真实 SDK 配合受控 API，视频使用受控响应，不代表远端服务或登录流程的生产验证。
