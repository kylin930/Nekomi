# v1.0.0 个性化审计记录

基线：main `92170a3`。保留现有 Astro / MDUI 2.1.5、布局、动效、评论适配与静态站点架构，不修改用户文章正文。

| 原位置 / 硬编码 | 对定制的影响 | 本轮处理 |
| --- | --- | --- |
| PostCard 的设计 / 日常 / 工程映射，theme.js 的 blossom / sky 色源，home.css 专用选择器 | 特定中文名字自动变色，其他用户无法配置 | `content.categoryColors` + 统一角色工具；HEX 交给 MDUI 生成浅深完整色组，无映射统一 primary；移除专用分支 |
| theme.js 的成功 / 注意色源 | 写作提示配色不能复用或调整 | `appearance.semanticColors`，沿用默认值，可供分类和 Markdown 复用 |
| Sidebar 的三个 Tab 名称 | 只能改源码 | `ui.sidebar.updates / friends / comments`，沿用内部 ID 与既有顺序开关 |
| urls 的 zh-CN 日期、BlogHome / 归档页的中文年月拼接 | 改 language 后格式仍为中文 | 统一 Intl 工具，站点语言格式化日期 / 归档标题；机器年月路由不变 |
| Sidebar 的固定上海时间，评论控制器的浏览器默认时区 | SSR 和运行时显示不一致 | `publishing.timeZone`，共用同一时间戳格式化实现；日历日期锁定 UTC，避免日期偏移 |
| Footer 的 UTC 年份、空副标题的标题分隔符 | 年界时与显示时区不符，空配置留多余符号 | 年份使用配置时区；空副标题不拼多余分隔符，SEO 描述沿用现有字段回退 |
| BlogHome 两处 slice(0, 3) | 分类 / 归档展示密度不可调 | 预览数量各 0–12，默认 3；0 不输出空列表，发现链接和分页不受影响 |
| Sidebar 静态示例评论 slice(0, 4) | 与已有最新评论数量配置不一致 | 复用 `comments.recentLimit`，没有新增重复开关 |
| Content schema 默认「未分类」与 relatedPosts 的文字判断 | 更换显示名或本地化会影响推荐 | 派生内部 `categoryKey`，默认分类为 null；兼容省略 / 空值 / 旧中文值，显示文案与推荐身份解耦 |
| Astro / runtime / Markdown 插件中的主题提示文字 | 标签、错误、空状态、阅读反馈各自写死 | 集中默认表 + 分组 `ui` 覆盖，构建端与浏览器共用；校验占位符，保留无障碍反馈；补齐空分类 / 标签 / 归档状态 |
| 卡片示例 / 置顶角标始终显示 | 不能只调整视觉而保留元数据 | `cards.example / pinned` 仅控制角标；不改变 demo 保护或置顶排序 |
| posts 的正则自动摘要保留 directive 围栏 | 省略摘要时可能显示组件语法 | 复用已有 Markdown 解析取纯文本，保留中文行内排版、手写摘要及 excerptLength；阅读估计仍使用原有规则 |
| 主 Tabs 只有四种内建内容 | 不能放普通页面入口 | `navigation.topLinks` 独立普通链接行，保留 Tabs / 静态路由 / Hash / 历史，不生成假面板或页面 |
| 字体只有系统字体栈 | 自托管字体需编辑组件 / CSS | 可选 WOFF2 @font-face，默认关闭、swap、适度预载、base 路径与系统回退；沿用三个既有字体栈 |
| 搜索大小写转换依赖宿主 locale，slug 同样受宿主影响 | 不同环境可能给出不同结果 / URL | 搜索使用站点 language；slug 使用确定性的 Unicode 小写，避免随显示语言改变 |
| 侧栏所有自定义链接均用外链箭头 | 站内入口语义不准确 | 根据已有 URL 选择站内 / 外链图标，不另加图标配置 |

已有 `site` 身份 / 社交、头像、壁纸、装饰、布局宽度 / 模块、卡片字段、阅读开关、友链、页脚、SEO 与第三方服务配置继续复用，没有再次开放一套同义设置。

以下保留为内部实现，不作为视觉配置：

- 内部 Tab ID、`recent` 必须启用的约束：关系到搜索、分页与旧 Hash。名称和其他启用 / 顺序仍可配置；普通页面通过独立链接扩展。
- 响应式断点、装饰安全尺寸、焦点 / 键盘补丁与 MDUI 注册策略：保护阅读宽度、遮挡与固定版本兼容性；现有布局尺寸和减少动态开关已提供适当自由度。
- 弹簧参数、动画复用机制、缓存容量、网络取消 / 去重、内部批次：属于正确性 / 性能常量。分页、预览和侧栏数量有各自明确的现有配置。
- slug / 标题锚点与稳定评论键、RSS / Sitemap / JSON-LD 的 ISO 日期和 demo 排除：维护可分享链接和索引规则，不跟随界面文案变动。
- 第三方 SDK 的内部文案 / DOM、安全解析长度、开发异常与协议错误：使用各服务官方语言选项；Nekomi 只配置自己的外层提示，不改写评论正文或暴露每条诊断为站点参数。
- 标准 Markdown 语法、Material Icons 的操作图标、阅读时间近似算法：保留功能语义；作者可以通过既有图标属性、文章阅读时间等设置覆盖适用内容。

验证配置：[默认](../site.config.json)、[中文个人站](../examples/personalized.config.json)、[英文通用站](../examples/journal.config.json)。新测试覆盖首页 / 文章 / 分类 / 标签 / 归档、侧栏、两种主题、手机、字体、静态输出、导航和评论日期；另跑既有 SEO、评论、阅读与列表恢复回归。实际结果见 [tests/RESULTS.md](../tests/RESULTS.md)。
