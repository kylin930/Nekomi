## 标题与段落 {#headings}

文章标题来自 Frontmatter，正文从二级标题开始。目录会根据二至六级标题自动生成，较小屏幕下可以折叠。

一个段落说清一件事。中文与代码混排时，可以使用行内代码，例如 `npm run dev`。需要强调时，使用 **粗体**；补充说明也可以用 *斜体*。

### 列表 {#lists}

- 无序列表适合并列的信息。
- 有序列表适合有先后关系的步骤。
- 内容之间保持简短、明确的关系。

### 引用 {#quotes}

> 引用可以用于摘录，也可以承载需要单独阅读的说明。注明来源比增加装饰更有帮助。

## 代码 {#code}

代码围栏后写语言名，就能得到语法高亮。长行在代码块内横向滚动，不会撑宽页面。

```js
const notes = ['记录', '整理', '分享'];
console.log(notes.join(' → '));
```

复制按钮默认开启，可以通过全站配置或单篇文章的 `reading.copyCode` 关闭。

## 表格与链接 {#tables}

| 内容 | 建议用途 | 是否必填 |
| --- | --- | --- |
| title | 文章标题 | 是 |
| date | 发布日期 | 是 |
| excerpt | 手写摘要 | 否 |
| updated | 实际更新日期 | 否 |

手机上可以在表格区域横向滚动。链接使用真实地址，例如 [Astro 文档](https://docs.astro.build/zh-cn/)。

## 写作之后 {#after-writing}

发布前检查标题、图片替代文字和链接。示例文章的 `demo: true` 会阻止它们进入公开索引；自己的文章可以明确改为 `false`。
