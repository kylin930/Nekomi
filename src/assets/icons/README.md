# 品牌图标来源

仅包含 GitHub 与 Bilibili 的独立 SVG，不引入图标库运行时或新字体。

- 来源：Simple Icons **15.1.0**，CC0-1.0；完整条款见 [LICENSE.md](LICENSE.md)。
- GitHub：https://github.com/simple-icons/simple-icons/blob/15.1.0/icons/github.svg
- Bilibili：https://github.com/simple-icons/simple-icons/blob/15.1.0/icons/bilibili.svg
- SVG 保留上游原始文件，Astro 按静态组件内联；大小与 `currentColor` 由主题样式控制。
- CC0 不授予品牌商标权；使用时仍需遵守各平台的品牌规范。图标不表示平台背书。

普通网站、邮箱、RSS 仍使用已有 MDUI / Material Icons，不用通用 Material 图标代替品牌标识。
